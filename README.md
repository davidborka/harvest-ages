# Harvest Ages — web build

**Play:** https://davidborka.github.io/harvest-ages/

Build a farm, then a civilization: from hand tools in the 1800s to mechanized farming and beyond. Grow 28 crops with real
soil, water and seasons, automate your farm with pumps, mills and machines, help the village, fish at the lake (including
ledger fishing with groundbait), explore cellars and the world, and play chess, origami, Farm Bird and Mole Patrol.
Learning activities adapt to the player's age. Hungarian and English. Progress is saved in the browser (IndexedDB).

This repository holds only the compiled browser build, published with GitHub Pages. The source code is private.
Best played in a desktop browser (Chrome, Edge or Firefox). On phones, use the Android app.
