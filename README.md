# Harvest Ages — web build

**Play:** https://davidborka.github.io/harvest-ages/

A farming game set in 1850–1900. Farm, learn through quizzes, adopt a pet, take on village quests.
Hungarian and English. Your progress is saved in the browser (IndexedDB).

This repository holds only the compiled browser build, published with GitHub Pages. The source code is private.
Best played in a desktop browser (Chrome, Edge or Firefox). On phones, use the Android app.
